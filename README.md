Guess the Number Game

About the Game

-Guess the Number is a simple Python game where the computer randomly chooses a number between 1 and 10.

-The player has 6 attempts to guess the correct number. After each valid guess, the game tells the player whether their guess is too high or too low.

How to Play

1. Run the game.
2. Enter a number between 1 and 10.
3. The game will tell you if your guess is too high or too low.
4. Keep guessing until you find the correct number or use all 6 attempts.
5. At the end of each game, choose whether you want to play again.
6. When you finish playing, the game displays your statistics.

Features

- Random number generation
- Maximum of 6 attempts per game
- Too high and too low hints
- Input validation
- Replay option
- Tracks the games played
- Tracks the games won and lost
- Tracks the total number of guesses

Game Statistics

The game keeps track of:

- Games played
- Games won
- Games lost
- Total guesses
